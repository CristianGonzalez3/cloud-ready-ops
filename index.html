Cloud-Ready Ops

Arquitectura web de tres capas en Google Cloud Platform.

Three-tier web architecture on Google Cloud Platform.

Objetivo

Objective

Diseñar, aprovisionar, configurar y documentar una arquitectura web de tres capas (Red, Cómputo y Base de Datos) en la nube pública, simulando la entrega técnica a un cliente corporativo.

Design, provision, configure and document a three-tier web architecture (Network, Compute and Database) on a public cloud, simulating a technical delivery to a corporate client.

Semana 6Week 6

Diseño y Redes

Design and Networking

Diseñamos el diagrama de arquitectura y creamos la VPC cloud-ready-ops-vpc (10.0.0.0/16), con subred pública y privada, y las reglas de firewall entre capas.

We designed the architecture diagram and created the VPC cloud-ready-ops-vpc (10.0.0.0/16), with a public and a private subnet, and the firewall rules between layers.

Semana 7Week 7

Cómputo y Servidor Web

Compute and Web Server

Levantamos servidor-web en la subred pública e instalamos Nginx para servir esta misma página.

We launched servidor-web in the public subnet and installed Nginx to serve this very page.

Semana 8Week 8

Base de Datos y Versionado

Database and Version Control

Desplegamos servidor-db en la subred privada (sin IP pública), con salida a Internet mediante Cloud NAT y Cloud Router, e instalamos MySQL con la base helpdesk_db. Documentamos y versionamos todo en GitHub.

We deployed servidor-db in the private subnet (no public IP), with Internet egress via Cloud NAT and Cloud Router, and installed MySQL with the helpdesk_db database. Everything was documented and versioned on GitHub.
